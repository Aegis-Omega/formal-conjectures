## Why a finite additive lower error is strong on an unnormalized class

For an ACTUAL homogeneous quadratic q on a test class closed under real
scaling, an inequality q(f)>=-epsilon for EVERY f, with one finite epsilon
independent of f, already forces q(f)>=0 for every f. If q(f0)<0, choose a
real scalar t with t²(-q(f0))>epsilon. Then q(tf0)<-epsilon, contradiction.
The scaling exists by the Archimedean property (or an explicit square root
when epsilon>=0). This argument does not assume that the abstract
QuadraticFormV1 function type has homogeneity; it applies to concrete forms
after that identity has been proved.

Thus a small numerical negative matrix value cannot be excused by an
unweighted epsilon_n on this unbounded class. A normalized domain or a
proved lower error proportional to energy would require an explicit valid
normalization/transport lemma. It is not a reason to silently weaken the
actual target or invent the missing finite lower bound.
