# Thirteen independent atoms of log-width 1/128 on the dyadic lattice

## What is new

There is one module, `WeilFineCombThirteenV1.lean`. It imports `WeilNineBlockMultiV1`
(`20261122_nine_packet_multi_v1`) and `WeilFineDiagonalQuadV1` (`20261122_fine_diagonal_quad_v1`).

Each block is `f_j = T_{j log 2} g_j`, for `j = 0, …, 12`. Every `g_j` satisfies
`LogSupportIn g_j (a − 1/256) (a + 1/256)`, with one common `a`, and both moment conditions. These are atoms of
the same width as those of the operator's fine Gram decomposition.

### Ingredients

* **Diagonal `43/10`** (`fine_diag`), from `fine_diagonal_43_over_10`.
* **Prime windows of radius `1/128`.**
  * `fine_logCross_zero` and `fine_mixed_inv_far` make the log-windows four times narrower than at width `1/32`.
  * `fwin1, …, fwin12` use `9922/10000 < e^{−1/128}` and `e^{1/128} < 10079/10000` (`exp_fine_lower`,
    `exp_fine_upper`, from the degree-3 Taylor bound). Every integer in the window that is not listed has two
    distinct prime factors.

  | gap `k` | prime powers in the window |
  |---|---|
  | `1, …, 7` | `2^k` only (at `k = 7`, `127` lies outside the window and `129 = 3 · 43`) |
  | `8` | `256, 257` |
  | `9` | `509, 512` |
  | `10` | `1019, 1021, 1024, 1031` |
  | `11` | `2039, 2048, 2053, 2063` |
  | `12` | `4073, 4079, 4091, 4093, 4096, 4099, 4111, 4127` |

* **Masses.** Each term is bounded by `Λ(m) m^{−1/2}` times the weighted Cauchy–Schwarz form
  (`term_norm_le2`).
  * `fmass_prime` and `fmass_pow2` bound each mass with `log m ≤ k log 2 + (m/2^k − 1)` (`log_le_pow2`) and a
    rational bound on `m^{−1/2}`.
  * `fps1, …, fps12` sum the masses into the ceilings `pbar13 k`.
* **Archimedean term** (`arch2`). Each cross term is at most `(E(p) + E(q))/400`.
* **Schur weights** `wv13 = (1, 112/125, 423/500, 143/200, 329/500, 571/1000, 569/1000, …)`, symmetric.
  The largest row coefficient is `3.6682 ≤ 37/10`.

### Result

`thirteen_atom_gram_bound`:

    Re Σ_{i,j} B(f_i, f_j)  ≤  −(3/5) · Σ_j E(g_j).

## Not done here

* **Free positions.** The atoms are on the dyadic lattice with a common base. The operator's fine
  decomposition places atoms on a `1/192` lattice; that is a different geometry.
* **The per-packet mixed budget** of the operator's chain remains open.
* Not RH.
